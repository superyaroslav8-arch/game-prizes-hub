# 🎁 Game Prizes Hub

Красивый и удобный сайт для выбора игровых предметов и призов.

## Как работает

1. **Платформа** — выбираешь, на чём играешь (PC, приставка, телефон, планшет, мини-приставка или любое)
2. **Игра** — Brawl Stars, GTA 5, GTA 4, Roblox, Among Us, Minecraft, Fortnite, Valorant, Genshin Impact, PUBG и другие
3. **Приз** — предлагаются готовые варианты + есть поиск, чтобы найти нужный скин / гемы / валюту самому
4. **Ссылка** — получаешь **реальную официальную ссылку** на магазин издателя

Все ссылки ведут только в официальные магазины (Rockstar, Steam, Supercell, Epic, Roblox, Hoyoverse и т.д.). Никаких генераторов бесплатных кодов.

### Как включить GitHub Pages (1 минута)

1. Открой репозиторий: https://github.com/superyaroslav8-arch/game-prizes-hub
2. Settings → Pages
3. Source: **Deploy from a branch**
4. Branch: **main** → folder **/ (root)** → Save
5. Через 1–2 минуты сайт заработает по адресу выше

## Локально

Просто открой `index.html` в браузере.
